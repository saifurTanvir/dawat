# E2E টেস্ট (Playwright)

ফোনের মাপের Chrome-এ আসল অ্যাপ চালিয়ে পুরো দিনের কাজ যাচাই করে: গৃহিণী, ক্রেতা, এলাকা ম্যানেজার, নিয়মিত গ্রাহক আর অ্যাডমিন। সব ডেটা ডামি। কোনো আসল SMS যায় না, কারণ টেস্টে SMS শুধু লগে লেখা হয়।

## চালানো

```bash
npm ci
npm run build                      # অ্যাপ public/build থেকে চলে
npx playwright install chromium    # একবারই (অথবা E2E_CHROME=/path/to/chrome দিন)
npm run test:e2e
```

- টেস্ট `dawat_test` ডেটাবেস ব্যবহার করে (phpunit-ও এটাই ব্যবহার করে)। প্রতিবার শুরুতে `migrate:fresh` চলে, তাই এটা কখনো আসল ডেটাবেসের দিকে দেবেন না।
- নিজে থেকে `php artisan serve --port=8010` চালু করে নেয়। queue `sync` থাকে, OTP-তে যেকোনো ৬ অঙ্ক চলে।
- রিপোর্ট দেখতে: `npx playwright show-report`

## কী কী আছে

| ফাইল | যা যাচাই করে |
| --- | --- |
| `public-pages.spec.js` | হোমের চার দরজা, কাছের খাবারের ফিড, লগইন ছাড়া "নিতে চাই", ফুটারে "এখন চালু" আর "শিগগিরই আসছি" আলাদা কিনা |
| `zone-day.spec.js` | উত্তর বাড্ডার একটা দিন: গৃহিণী "রান্না করে আয় করুন" পড়ে যোগ দেন (নিজের নাম, দিনে কয় প্লেট) → অ্যাডমিন অনুমোদন দেন → পোস্ট, WhatsApp-এ জানানো → ক্রেতা নাম আর নোট দিয়ে "নিজে নেব" বুক করেন → গৃহিণী নাম-নোট দেখেন, "দিয়েছি" দেন → অ্যাডমিন এলাকা ম্যানেজার আর নিয়মিত গ্রাহক যোগ করে জুটি বাঁধেন → গৃহিণী নতুন গ্রাহকের খবর পান → "রেডি" → এলাকা ম্যানেজার সোজা নিজের তালিকায়, ম্যাপ লিংক, ভুল কোডের এরর কার্ডে, নগদের টিক খালি → গৃহিণীকে দরজায় টাকা, গৃহিণী নিশ্চিত করেন → "টাকার হিসাব" মেলে → গ্রাহক তারা দেন → অতিথির খাবার → শেষ হওয়া পোস্টে প্রশ্ন |

যেসব টেস্টের নাম "জানা সমস্যা" দিয়ে শুরু, সেগুলোতে `test.fail()` দেওয়া আছে। এগুলো QA অডিটে পাওয়া বাগ, তাই এখন ফেল করাটাই প্রত্যাশিত। বাগ ঠিক হলে টেস্টগুলো লাল দেখাবে ("Expected to fail, but passed")। তখন `test.fail()` লাইনটা মুছে দিন।
